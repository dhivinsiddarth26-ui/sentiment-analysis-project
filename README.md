# Sentiment Analysis Project

A Streamlit web application that analyzes social media comments using NLP and TextBlob.

## Features
- Single comment sentiment analysis
- CSV upload and bulk analysis
- Bar chart visualization
- Download results CSV

## Technologies
- Python
- Streamlit
- Pandas
- NLTK
- TextBlob
- Matplotlib
